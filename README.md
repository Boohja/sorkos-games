# Games at Sorkos

A static SvelteKit collection of focused game reference tools for `games.sorkos.net`.

## Developing

Install dependencies and start the development server:

```sh
npm run dev

npm run dev
```

## Building

Create the fully prerendered production build:

```sh
npm run build
```

The project uses `@sveltejs/adapter-static` with SvelteKit prerendering. Vercel can deploy the
repository using its SvelteKit framework preset and the default build command.
